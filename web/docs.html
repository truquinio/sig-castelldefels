Qué representa el dashboard

La unidad visible es el establecimiento observado: una presencia económica localizada que puede estar descrita por OpenStreetMap, Overture o ambas fuentes. No es todavía un establecimiento administrativo municipal ni el Censo de Actividades Económicas.

El objetivo es localizar, contar, clasificar y detectar discrepancias entre fuentes abiertas. Una futura versión interna podría relacionar estos establecimientos con identificadores, expedientes y situación administrativa, pero esos datos no forman parte de esta versión pública.

Conciliación de establecimientos

Los registros OSM y Overture se comparan por nombre, categoría y proximidad. Si coinciden de forma suficiente se interpretan como observaciones del mismo establecimiento; en caso contrario permanecen separados.

  • 216 registros proceden sólo de OSM.
  • 642 proceden sólo de Overture.
  • 127 están corroborados por ambas fuentes abiertas.
  • Los nombres no disponibles se sustituyen por etiquetas semánticas, nunca por nombres inventados.

Método espacial

La malla de 500 m se construye en ETRS89 / UTM 31N (EPSG:25831), adecuado para medición métrica en Castelldefels. El resultado se transforma a EPSG:4326 para GeoJSON y visualización web.

Las celdas muestran concentración de registros observados; no miden empleo, facturación, afluencia ni densidad económica real.

Limitaciones

  • Las fuentes abiertas pueden contener omisiones, duplicados, cierres no reflejados o categorías imperfectas.
  • El inventario actual usa OSM + Overture, mientras que la serie 2016–2025 es histórica OSM; por ello se muestran separadas y no se conectan como una única serie comparable.
  • El histórico se utiliza como contexto de evolución de lo cartografiado en OSM, no como histórico de altas, bajas, licencias o expedientes municipales.
  • Una imagen Panoramax cercana se etiqueta como imagen de entorno, no como fotografía verificada del comercio. Si no existe una referencia fotográfica suficientemente próxima o explícita, la ficha lo indica y no inventa una fachada.
  • No se utilizan datos internos ni expedientes municipales en esta versión pública.
